# 正文排版基准

本轮以 Typora 官方 GitHub 默认主题为明确基准，而非 Obsidian 的可定制主题。
来源：https://github.com/typora/typora-default-themes/blob/master/themes/github.css （2026-10-04 核对）

| 项目 | 基准 |
| --- | --- |
| 默认正文 | 16 px / 1.6 行高 |
| 字体 | 离线 Open Sans，中文使用系统回退字体 |
| 内容区 | 最大总宽 860 px（正文 800 + 左右各 30） |
| 宽屏 | 编辑视口 ≥1400 时 1024 px；≥1800 时 1200 px |
| 顶部 / 底部留白 | 30 / 100 px |
| 标题 H1–H6 | 2.25 / 1.75 / 1.5 / 1.25 / 1 / 1 em |
| 标题行高 | 1.2 / 1.225 / 1.43 / 1.4 / 1.4 / 1.4 |
| 标题上下间距 | 1 rem；H1/H2 有底边线 |
| 段落、列表、引用、表格 | 上下 .8 em，相邻外边距按最大值合并 |
| 嵌套列表上下间距 | 0 |
| 列表缩进 | 30 px |
| 代码字号 | .9 em |
| 围栏上下间距 | 15 px |
| 表格单元格 | 上下 6 px，左右 13 px |

CodeMirror 的源码区域保留空白；渲染块显式使用 `white-space: normal`。结构块之间的源码空行不额外占据高度。当前光标所在的空行仍可输入，全文源码模式保留所有空行。文件内容不被修改。

用户已有字号和宽度偏好继续保留；设置中的「恢复 Typora 默认排版」应用 16 / 800 基准。工具栏与 macOS 窗口仍使用本应用的原生界面。此处校准的是正文排版规则，不表示复刻 Typora 的全部交互或不同版本的像素级输出。

字体来自 Typora 官方默认主题仓库的 `themes/github/{400,400i,700,700i}.woff`，其内嵌许可为 Apache 2.0，随应用保留声明。
