目标：通用 Markdown、GFM 常用扩展、公式、脚注、高亮、YAML、Mermaid 和提示块。保留原始 Markdown 文本，渲染不序列化或重写文件。

- [x] 原生文档与离线编辑引擎集成，文件读写、撤销、查找、设置、大纲
- [x] CommonMark：标题（含 Setext）、段落、换行、嵌套强调、引用、列表、代码、链接、图片、转义、实体、HTML
- [x] GFM：表格及对齐、任务列表交互、删除线、自动链接
- [x] 扩展：脚注、数学公式、高亮、YAML、Mermaid、提示块
- [x] 格式组合、Unicode、原文保留、中文文本输入、源码切换、资源打包验证
- [x] 实际笔记窗口排版检查（标题、段落、列表及代码块）
- [x] 临时文档首次保存、自动保存、外部修改冲突与重新载入
- [ ] 人工检查实际输入法候选状态
- [x] 完整构建、自动测试与使用说明

不包含第二阶段 Obsidian 双链、笔记嵌入、块引用和插件语法。HTML 支持静态排版，脚本和事件属性不会执行。

## 已知差异

- 结构块整体显示源码，不提供表格行列工具栏或 YAML 属性表单。
- 公式使用 KaTeX 的 TeX 子集，个别 MathJax 专有命令不兼容。
- HTML 仅支持静态内容；脚本、事件处理器、iframe、表单不执行。
